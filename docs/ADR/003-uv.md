# ADR 003 — uv e quatro escopos Python

Status: adotada na implementação inicial, 2026-11-03.

uv gerencia CPython do usuário, ferramentas CLI isoladas, dependências .venv de
cada projeto e execuções temporárias com uvx. São escopos distintos. Não usamos
pip global, Python do sistema como destino, ambiente único compartilhado ou
alteração global de UV_PROJECT_ENVIRONMENT.

Interpretadores usam versões patch e --no-bin. CLI usam versões exatas e um
CPython gerenciado declarado. Bibliotecas científicas ficam num exemplo com
pyproject/lock e não entram no perfil science. O custo é atualizar manifestos
por revisão e validar wheels por plataforma; ter um lock não certifica GPU,
musl ou aarch64.
